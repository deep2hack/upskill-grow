# Upskiller Academy – Professional Education & Training Platform

A modern, responsive education and training website developed for Upskiller Academy, focused on financial education, professional skill development, and career opportunities.

## Project Overview

Upskiller Academy provides structured learning programs in financial markets, trading, investment analysis, and related professional skills.

I developed and currently manage the website, including its frontend experience, content structure, lead-generation workflow, and ongoing improvements.

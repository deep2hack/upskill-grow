# Project rules
- Course prices are optional and must only render when provided, so new programs never display invented fees.
- The astrology program uses a dedicated detail component through the existing course route, preserving existing program pages.
- Explicit course enquiries use a shared browser event handled by the existing lead popup; automatic suppression must not prevent user-requested enquiries.
- Uploaded course posters use asset pointer imports and uncropped image rendering to preserve their original content.
